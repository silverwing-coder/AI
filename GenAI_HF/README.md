    We need explicitly pass down quantization and data-type arguments

    $ pip install bitsandbytes accelerate

# 1. Configure 4-bit quantization to fit your 7.53 GiB GPU

    load_in_4bit=True,

    model=model_id,

    }

<h3>Parameters of model(): message</h3>

<b>A. Core message roles:</b>
<ul>
    <li> system: sets the behavior, tone, and content</li>
    <li> user: represents the questions or commands input by the human</li>
    <li> assistant:represents the prior responses generated by the AI model </li> 
</ul>
<b>B. Example messages in code: json</b><br>
[<br>
  &emsp;{"role": "system", "content": "You speak like a pirate."},<br>
  &emsp;{"role": "user", "content": "Hi, what is the weather today?"},<br>
  &emsp;{"role": "assistant", "content": "Ahoy matey! 'Tis clear skies ahead!"},<br>
  &emsp;{"role": "user", "content": "Should I wear a jacket?"}<br>
]</br>

<b>C. Reason for using message array </b>
1.  Context tracking: model reads the full list of previous messages to understand follow ups
2.  Role authority: separating system instructiions from user inputs prevents the user from
    overiding core safety or functional rules
3.  Chat templates: local models use specialized chat templates to cover the message list into
    the exact text tokens the model expects
